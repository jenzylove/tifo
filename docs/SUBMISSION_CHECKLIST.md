## Required by Tameion
- [ ] Public GitHub repo
- [ ] Demo video under 3 minutes (Loom, YouTube or Vimeo)
- [ ] Live product link
- [ ] Traction answers: businesses onboarded, value moved, problems solved
- [ ] Built on Arc, with payments in USDC
- [ ] Real usage during the event window (real sellers and buyers, not bots or self-transfers)

## Judging evidence
- [ ] Agentic: decision log showing match choice, pricing, rebalances, cover decision and settlement, each with reasons
- [ ] Traction: number of sellers, distinct buyer wallets, USDC volume and refunds settled, read live on `/proof`
- [ ] Circle tools in real use: USDC on Arc, Circle Wallets (passkey), Gateway/CCTP pay-in, gas sponsorship, contracts
- [ ] Innovation: a two-sided, self-balancing promo, explained in the README

## Product claims
- [ ] Refunds land within seconds of the result (explorer timestamps)
- [ ] Worst case known before kickoff (contract invariant plus live book)
- [ ] Agent cannot withdraw funds (contract test)
- [ ] Video of a real buyer receiving a refund
