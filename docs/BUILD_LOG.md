## 4 Oct 2026: redesign around the shop (after user feedback)
User feedback on the first design: mocky, raw data everywhere, the price looked like "a random wallet" instead of the seller's product, no landing page, no place for a business to set up its shop, and the AI-as-manager was invisible.
Changes (references: Pinterest pins 17 for the landing page, 22 for the storefront, 09 for the AI manager):
- `TifoShops` registry on testnet `0x30444d0006e530cc76418275A421E2665828666d`: handle, branding, links and catalog JSON, owned by the shop's wallet.
- Landing page `/`, live board `/drops`, storefront `/s/[handle]`.
- Drop page is now product-first: shop photo and price, team picker, quantity, Circle checkout, "send delivery details on WhatsApp" after paying. Contract data moved under "Behind this drop".
- `/manage`: passkey sign-in, shop editor with image uploads (Vercel Blob store `tifo-media`), drop launcher priced with the core math, manager chat that knows the catalog, an AI briefing (Claude, structured JSON) with one-tap moves, KPIs read from the chain, USDC payouts.
- Verified live: the briefing read the test shop's real numbers ($4.00 sales, $0.83 held) and proposed real fixtures and catalog products. The chat proposed Chelsea v Bournemouth on the catalog tee at the catalog price.
