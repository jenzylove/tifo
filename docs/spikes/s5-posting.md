# S5: Posting result moments to X

**Question:** Can the agent post to X by itself?

**Finding:** Posting through the X API needs the user's developer account and paid or pay-per-use API credits. There are no credentials in this session.

**Verdict: fallback chosen.** The agent drafts every launch and result post. The seller (or we) publish it with a one-click X share link (`https://x.com/intent/post?text=...`). Auto-posting can be switched on later if the user adds X API credentials. No result post is ever published without a real settled promo behind it.
